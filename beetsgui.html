            Beets convert → ALAC (ffmpeg)
            ℹUses beets' own convert plugin with ffmpeg. Makes copies — originals are NOT deleted automatically. Requires: pipx inject beets beets-convert + brew install ffmpeg
          

          

            Important: beet convert makes copies of the files — originals are untouched. Verify the output before deleting originals manually.
          

          

            Add to config.yaml (Preferences does not enable convert automatically — paste manually):

            
convert:
  format: alac
  never_convert_lossy_files: yes
  formats:
    alac:
      command: ffmpeg -i $source -c:a alac -map_metadata 0 $dest
      extension: m4a

          Discogs
          ▼
        

        

          

            
            
          

          

            

              
              

                

                
              

            

            
1. Log in to Discogs → Settings → Developer
2. Click "Generate new token" → copy token

          

          

            
OAuth happens automatically when you run beet import for the first time with the discogs plugin active. Beets opens a browser and saves the token to ~/.config/beets/.

          

          
⚠ Discogs token gives full access to your account — keep it private.

          Beatport4
          ▼
        

        

          
Requires: pipx inject beets beets-beatport4
Plugin must be named beatport4 in config (not beatport).

          

            
            
          

          

            

            

          

          

            
1. Log in to beatport.com in Chrome/Edge
2. Open Developer Tools (Cmd+Opt+I) → Network
3. Filter on "token" → find POST request → copy Response JSON
4. Save as ~/.config/beets/beatport_token.json
Token is read automatically by the plugin.

          

          

            

            

          

          
⚠ Login credentials stored in plain text in config.yaml.
